Cozy Harvest UI - free pixel-art UI pack by denizlabs
Warm wood and fabric UI for farming and cozy games.

34 UI pieces in one style, ready for your engine:
  png/            every piece at 1x, with nine_slice.json (the margins that must not stretch)
  png_4x/         the same pieces at 4x
  font/           a matching pixel font (BMFont)
  godot/          a ready Godot 4 theme; godot_demo/ is a small project that shows it
  unity/          sprites with their 9-slice borders set automatically
  gamemaker/      sprites plus a setup script
  rpgmaker/       a window skin (Window.png) for RPG Maker MZ / MV
  aseprite/       the whole kit as an .aseprite file, every piece a named slice
  construct3/, gdevelop/, other-engines/   step-by-step setup notes
Each folder has a README with the steps. Use nearest-neighbour (no) filtering to keep pixels sharp.
